# Feature Proposals

This directory contains planned or proposed behavior that is not yet implemented.

Unlike `docs/specs/`, these documents are not implementation-backed feature specifications. When a proposal is implemented, move the finalized behavior into the appropriate `docs/specs/*.md` file and update user guides, tests, and IPC contracts in the same change.
